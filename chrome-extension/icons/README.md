# Extension Icons

This directory should contain the following icon files:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create these icons using any image editing software. The icons should represent the deepfake detection functionality.

### Quick Option: Use Online Tools

1. Create a simple icon design (e.g., a shield with a checkmark, or a camera with an AI symbol)
2. Use an online tool like:
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/
   - Or any image editor that can export PNG files

3. Export at the required sizes: 16x16, 48x48, and 128x128 pixels

### Temporary Placeholder

For development, you can use simple colored squares or download free icons from:
- https://icons8.com/
- https://www.flaticon.com/
- https://fontawesome.com/

## Icon Design Suggestions

- Shield icon (security/verification)
- Camera with AI/neural network symbol
- Checkmark with video icon
- Eye with verification badge

Make sure the icons are clear and recognizable at small sizes (especially 16x16).
